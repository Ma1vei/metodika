# МиграПро — WordPress-тема

Кастомная адаптивная WordPress-тема для сайта миграционного агентства «МиграПро», выполненная по макету Figma.

## Возможности

- адаптивная шапка сайта;
- мобильное бургер-меню;
- выпадающее меню услуг;
- первый экран с двумя сценариями обращения;
- блок офисов и статистики;
- модальное окно консультации;
- маска и проверка номера телефона;
- поддержка меню WordPress;
- поддержка полей ACF с резервными текстами;
- адаптация под мобильные и десктопные экраны.

## Технологии

- WordPress
- PHP
- HTML5
- CSS3
- JavaScript
- Advanced Custom Fields — опционально
- Inter через Google Fonts

Сборщики и дополнительные JavaScript-зависимости не используются.

## Установка

1. Скопируйте папку темы в:

   `wp-content/themes/custom-theme`

2. Откройте панель управления WordPress.

3. Перейдите в **Внешний вид → Темы**.

4. Активируйте тему **Custom Theme**.

## Настройка меню

1. Перейдите в **Внешний вид → Меню**.
2. Создайте главное меню.
3. Назначьте ему область:

   **Главное меню (Шапка)**

Поддерживаются вложенные пункты второго уровня, которые отображаются в выпадающем меню.
